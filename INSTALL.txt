This updates the notation table injected into the original report-writing
functions. It preserves the original field-sorted UV Lagrangian, UV/EFT1 RGE,
and RGE structure/prefactor table writers. No Matchete/RGBeta physics changes.

PowerShell from project root:
  Expand-Archive -LiteralPath "$HOME\Downloads\T3_Complete_Coupling_Notation_Index.zip" -DestinationPath . -Force
  python -X utf8 -m pytest -q tests/python/test_general_coupling_inventory.py
  python -X utf8 pipeline.py --hypercharge-comparison --reports-only

The table contains registry-defined coupling field contents and contraction
labels and names of couplings found in the saved Lagrangian and RGBeta betas.
If a coupling is not defined by the registry, the report explicitly says its
operator definition is unavailable rather than inventing a definition.

The standard original notation key is retained. Named additional quartics
lambda7 through lambda12 are included when those parameters appear in the
selected model results.
