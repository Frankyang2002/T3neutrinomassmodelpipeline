# Project-relative file inventory

All files below install under the single new directory `Numerical/lo_certification/physical_normalisation/parallel_A_spinor/`, preserving repository paths. Full replacements (not patches) are supplied for each newly created executable. No existing file is replaced.

- `ROADMAP.md`: fixed A0–A4 roadmap.
- `STATUS.md`: individual milestone completion/obstruction record.
- `DERIVATION.md`: explicit common Weyl/4-spinor and SU(2) convention.
- `REPORT.md`: pass/fail, residuals, physical gate, blocker.
- `RUN.md`: non-overwriting PowerShell execution, native and offline paths.
- `EVIDENCE_PROVENANCE.json`: checked public source references and saved native witness paths.
- `weyl_algebra_check.py`: standalone exact Grassmann/symmetric-mass test.
- `native_rule_probe.wl`: standalone *new* installed-Matchete FeynmanRules test (blocked here).
- `complex_three_models.py`: standalone 3-case complex UV one-loop calculation; `native` witness-gated or labelled `audited-constants` mode.
- `evidence/exact_weyl_algebra.json`: actually executed pure-mathematical proof result.
- `evidence/audited_constants_three_models.json`: actually executed conditional three-model numerical results.

Native run outputs are **not** stored in this ZIP because they could not be generated in this environment. They must be saved under a fresh `output/general_observable/physical_normalisation/parallel_A_spinor_<timestamp>/` directory on the user's local machine. The included `evidence/*` values are not presented as installed-native observations.
