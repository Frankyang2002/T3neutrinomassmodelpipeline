# Stage 11: Quarantine exact duplicate TeX reports

Place `tools/QuarantineDuplicateTex.py` in the repository root at the indicated path.

Requirements: the existing `duplicate_tex_audit.csv` generated by `python -m tools.AuditDuplicateTex`.

```powershell
python -m tools.QuarantineDuplicateTex
Import-Csv .\duplicate_tex_quarantine_preview.csv | Group-Object status | Select-Object Name,Count
python -m tools.QuarantineDuplicateTex --apply
python -m tools.QuarantineDuplicateTex --restore
```

All operations are local. The program checks SHA-256 of each file against its chosen canonical document immediately before moving it. Only exact `.tex` duplicates beneath `Reports/output/full/` are eligible. The originals are moved under `.cleanup_quarantine/duplicate_tex/`; a persistent JSON manifest tracks every move. It never deletes numerical data or rewrites symbolic expressions. Don't remove the quarantine folder until you have checked any scripts that expect the old TeX report paths.
