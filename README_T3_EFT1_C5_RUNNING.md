This package is **local-only**. It replaces the previously supplied dashboard
adapter, not the original template or any Matchete/RGBeta physics source.

## What can actually be calculated today

The installed model-specific Matchete source provides an LLSS tree seed. The
repository already contains a full seven-term master `psi^2 phi^2` one-loop
beta evaluator in `RGE/general/WilsonTensorRGE.py` and the guarded numerical
`RGE/running/intermediate/GeneralEFT1C5Mixing.py` source mixer. For a
**fully normalized, independently certified master-Weyl boundary** it returns:

\[
\Delta C_5(\mu) = \frac{\beta^{(1)}_{C_5}(\mu_F)}{16\pi^2}\ln(\mu/\mu_F),
\quad \mu_F=10^5\,{\rm GeV},\ \mu_S=10^3\,{\rm GeV}.
\]

The adapter now actually calls that existing function, validates the returned
complex symmetric `3 x 3` matrices, source provenance and scale endpoints,
and draws the **source-only** log norm and six independent matrix-element
magnitudes in the original **yellow EFT1 region**. It **does not** add these
contributions to the current green SMEFT `C5` boundary. To avoid double
counting, the finite joint-scalar threshold needs a matching-log subtraction.

Source input location per model (for example `A_m2`):

`output/general_observable/lo_eft1_mixing/certified_boundaries/A_m2/boundary.json`

Alternative root:

```powershell
python -X utf8 -m scripts.BuildT3OriginalColouredRGE `
  --certified-boundary-root "PATH\TO\certified_boundaries"
```

The boundary must have `format=t3-eft1-certified-master-weyl-v1`, `authority=certified`, `scheme=MSbar`, the complete scalar and flavour tensors, both gauge generator sectors, and nine independent physical certificates. The installed source solver enforces these. **Do not change synthetic fixtures to `authority=certified`, invent the nine certificates, or use the legacy ordered Matchete tensor as canonical** to make a line appear.

As of the inspected GitHub `main`, only `synthetic_input` and `synthetic_results` were present under `output/general_observable/lo_eft1_mixing`, not complete certified boundaries. Hence **the current general fitted campaign is expected to report `MissingCertifiedBoundary` and not draw a physical EFT1 C5 curve** until the normalization and EFT1 coupling dictionary are actually derived. This is an input physics gap, not a plotting bug. The key missing certification is the Matchete `GammaCC`/PL to two-component Weyl operator phase/sign/factor; also operator closure, gauge/Yukawa/quartic dictionaries and finite subtraction need checking.

You can run the existing synthetic RGE algebra tests separately, but they are **not physical predictions**:

```powershell
python -X utf8 -m unittest discover -s tests -p 'test_general_eft1_c5_mixing.py' -v
```

The existing `scripts/AdaptCertifiedEFT1Boundary.py` accepts two truly independently certified input files (canonical master-Weyl and EFT1 coupling/generator context), and merges/validates them into a boundary. It does not derive certificates by itself.

## Output status and physics scope

| Output | Meaning |
|---|---|
| `interactive_RGE.html` | The actual original coloured dashboard, regenerated in place |
| `eft1_c5_readiness.json` | Model-by-model reasons for missing/rejected certified EFT1 boundary |
| `<model>/eft1_c5_source.json` | Only created after external certified source passes the guarded seven-term evaluator |
| `<model>/eft1_c5_error.json` | Rejected source details, when present |
| `<model>/smeft_trajectories.json` | Genuine sampled **SMEFT** `C5` ODE solution from conditional one-scale scalar matching |
| `<model>/smeft_observables.csv` | SMEFT masses, mass-squared differences and mixing angles |
| `original_coloured_rge_status.json` | Full run status and removed obsolete file names |

**Not completed:** full LLSS Wilson self-running/complex anti-linear closure; fully calibrated Matchete-to-master tensor; independent finite joint-scalar matching; coupling the EFT1 log to the correct subtracted scalar-threshold `C5`. The green SMEFT data still use the previous **conditional one-scale** matching. Do not call the assembled report a fully certified sequential EFT result.

**Model coverage:** the original general dense UV/EFT1 trajectories cover 14 nonmixed models. The conditional B(-1)/C(-1) cases have no equivalent saved scale-resolved trajectories in this study. Missing physical C5 logs are never backfilled from synthetic test data or displayed as successful calculations.
