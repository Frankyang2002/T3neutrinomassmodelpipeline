## Algebra

In the mixed case, at the fermion threshold the boundary is in `X_F,Y_F`, but the scalar endpoint is described at μS by a different mass rotation `U_S`. The code derives the **real** `8×8` map from the documented exact complex field identity

\[
  \begin{pmatrix}S_1\\\epsilon S_2^*\end{pmatrix}
   = U_F\begin{pmatrix}X_F\\Y_F\end{pmatrix},\qquad
   \epsilon=\begin{pmatrix}0&1\\-1&0\end{pmatrix}.
\]

Write `s_original=R_F s_source` and `s_original=R_S s_muS_eigen`. For the full eight-real-mode tensor,

\[
 \lambda^{F}_{ABij}=\sum_{a,b}(R_F)_{ai}(R_F)_{bj}\lambda^{\mathrm{Matchete}}_{ABab},
 \qquad
 M_F^2=R_F^T R_S\,\mathrm{diag}(m_{X_S}^2\,\mathbf1_4,m_{Y_S}^2\,\mathbf1_4)R_S^T R_F.
\]

Neither scalar is integrated at μF. Both are integrated **jointly** using `Numerical.joint_scalar_matching.core.scalar_bubble_matching` at one μS. Source-resolved `C_LLSS(muF)` is contracted against only `lambdaT3` in this first numerical pilot.

\[
 B_{pqijAB}^{(\lambda T3)}=\sum_{a,b} C^{\mathrm{formal}}_{pqijab}(\mu_F)\,\lambda^{F,(\lambda T3)}_{ABab}(\mu_S),
 \quad
 \Delta C_5^{\rm log}=\Pi_W[B]\frac{\log(\mu_S/\mu_F)}{16\pi^2}.
\]

The joint-scalar bubble has the existing project's `-B0bar/(2*16π²)` convention, counted exactly once. The independent full-SU(2) Ward residual is mandatory; if either full tensor does not project to the Weinberg structure at tolerance `1e-8`, the runner exits with status 2 and gives **no neutrino mass estimate**. The fixed-input matching-scale-log cancellation is tested numerically.

**Normalization translation:** `Numerical.joint_scalar_matching.core.weinberg_tensor()` uses a template twice the `GeneralEFT1C5Mixing.py` master `(1/2)C5 (L.H)^2` template. Hence `C5_master=2*C5_joint_projection`. The output uses *master* C5 everywhere. For an assumed absolute `N_GammaCC`, the mass singular values are from

\[
 m_\nu=\tfrac12 v^2 N_{\Gamma CC} C_5^{\rm master},\quad v=246.22\ {\rm GeV};\qquad
 1\ {\rm GeV}=10^9\ {\rm eV}.
\]

Values are reported **per `|N_GammaCC|`**, not in certified physical eV, and require the scalar-source/RGBeta coupling hypothesis. This is an *LLSS-induced one-loop, lambdaT3-only* calculation: no direct UV hard-F contribution, no independent Weinberg boundary and no other EFT1 mixing terms are included.
