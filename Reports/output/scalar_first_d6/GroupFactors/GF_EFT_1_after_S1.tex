\section*{Stage-specific group-factor status}
The threshold ordering at this stage is supported by the report layer, so a PDF is produced for it.  A dedicated analytic renormalisable-RGE group-factor module is not currently available for this reduced heavy-field content.  Coefficients from the UV theory or from the special $F$-first EFT are therefore not reused here, because doing so would assign beta-function coefficients from the wrong dynamical theory.
