 2. It checks each directory's local file count and bytes against the exact

 4. It checks local git status for changed/untracked candidate outputs.

    member against SHA-256 before any moves.

    the sibling directory T3_thesis45_local_archives.
 7. It does NOT call git push, GitHub APIs, or mutate a remote repository.
