# T3 B(−1)/C(−1): conditional EFT2(H,X) → SM large-batch implementation

## What this package does

**New local-only experimental code** advances the existing numerically verified
EFT1 → Y-threshold tree projection to an *end-to-end conditional* neutrino-mass
calculation, with no changes to existing production code or prior results.

1. Validates the existing `bc_y_threshold_projection_v1` report and NPZ tensor;
   verifies the source's complete recorded SHA256 inventory again.
2. Re-evolves the exact **same** `continuous_v1` EFT1 RG state down to µY.
3. Interpolates the original 12-real-scalar **potential quartic tensor** to µY,
   rotates it with the exact real field map from the Y output, and restricts to
   H,X. Fits every component of the resulting 8⁴ tensor against the six real
   parameters of the inert-doublet scalar quartic basis; rejects a residual
   above `1e-7` or an incorrect λH normalization.
4. Evolves the one-loop renormalisable **H,X-only** beta functions, including
   the gauge contribution of one remaining complex scalar doublet, coupled
   quartics, running Higgs/inert mass parameters and full 3×3 SM Yukawas.
   The SM one-loop Yukawa/gauge numerator is reused from
   `RGE.running.weinberg.WeinbergRGE.sm_weinberg_beta`.
5. Solves the **new** self-consistent µX crossing using the X-only scalar EFT.
6. Rotates the original SU(2) gauge-generator/Yukawa static tensors with the
   previously verified real mass-basis map; drops Y. Reuses all seven
   contractions of the project's `psi2phi2` Wilson RGE in the eight-real-scalar
   EFT2. Six independent physical lepton flavor pairs remain explicit.
7. At µX, projects the Weinberg (HH) block of the evolved EFT2 Wilson tensor;
   solves the existing **full SM+Weinberg** evolution from µX to 100 GeV;
   computes **conditional** neutrino-mass singular values and an NO
   oscillation-observable diagnostic.
8. Saves non-overwriting JSON/NPZ/CSV plus hashes and false physical flags.

## EFT2 scalar conventions

The mass basis uses H with `Y=+1/2` and X with `Y=−1/2`. Define
`η=ε X*`, where `ε=[[0,1],[-1,0]]`. In real components
`H_a=(h_{2a}+i h_{2a+1})/√2` and similarly for X.

```
V4 = lambda1/2 (H†H)^2 + lambda2/2 (η†η)^2
     + lambda3 (H†H)(η†η) + lambda4 (H†η)(η†H)
     + (lambda5/2 (H†η)^2 + h.c.)
```

`lambda5` is complex. The six real fit parameters are λ1, λ2, λ3, λ4,
Re(λ5), Im(λ5). The **real scalar potential** quartic tensor uses
`V4 = q_abcd φ_a φ_b φ_c φ_d / 4!`, with all four tensor indices symmetric.
The fitted tensor is checked against all `8^4=4096` entries, not just six probes.

The β functions are the standard exact-Z2 inert-doublet one-loop equations
with `16π² d/dlnµ`, `gY` in **SM non-GUT-normalised** convention, and `λH`
the coefficient of `(H†H)^2/2`. The implementation allows complex λ5.
For reference the scalar-sector formulae in this convention include

```
βλ2=12λ2²+4λ3²+4λ3λ4+2λ4²+2|λ5|²
    +¾(3g2⁴+gY⁴+2g2²gY²)−3(3g2²+gY²)λ2
βλ5=λ5[2(λ1+λ2+4λ3+6λ4)−3(3g2²+gY²)+2T]
βmX²=[6λ2−(9/2)g2²−(3/2)gY²]mX²
      +(4λ3+2λ4)mH²
```

where `T=Tr(YeYe†)+3Tr(YuYu†)+3Tr(YdYd†)`. The λ1 beta includes the
usual SM expression plus `4λ3²+4λ3λ4+2λ4²+2|λ5|²`. The other
β functions are implemented in `T3BCEFT2HX.py`, with SM beta sourced from
`WeinbergRGE.py`. See the inert-doublet one-loop RGE literature and the
project's original RGE convention for independent future cross-checks.

### Limitations that remain

**This batch does not fully certify physical one-loop matching or a physical
neutrino spectrum.** The following are still absent:

- finite one-loop Y-threshold correction `ΔC_Y`, including renormalised
  heavy–light pieces, wavefunction and counterterm convention;
- finite one-loop X-threshold correction `ΔC5_X`;
- full three-family charged-lepton flavour anomalous-dimension structure of
  the EFT1/EFT2 Wilson tensor (the existing one-generation gauge-index master
  with six explicit **external** lepton flavour pairs is kept unchanged);
- remaining uncertified Stage29 RGBeta-to-Matchete additional-quartic mapping;
- an independent running Higgs quadratic-mass EFT1 initial condition (not
  present in the upstream source). The EFT2 runner uses the explicitly
  flagged tree proxy `mH²(µY)=−lambda1(µY)*vev²/2` and then runs it. This
  uncertainty affects the corrected µX;
- higher-dimensional operators generated by scalar tree thresholds and their
  subleading power-suppressed feed-down, if precision requires them.

These limitations are stored as **false physical-certification flags**, not
silently presented as physical matching at zero. Consequently, the output
neutrino masses are labelled *conditional leading-log/tree-scalar-threshold
benchmarks*. They are not a fit to oscillation data or fully physical spectra.

## Commands (PowerShell)

From `C:\thesistemp\T3neutrinomassmodelpipeline` after unpacking the ZIP:

```powershell
python -m unittest discover -s tests -p "test_t3_bc_eft2_hx.py" -v

python -u -X utf8 -m scripts.RunT3BCEFT2Sequential `
  --all --run-id continuous_v1 `
  --y-output-id bc_y_threshold_projection_v1 `
  --output-id bc_eft2_sequential_v1
```

The output directory is
`output/studies/general_scalar_extended/continuous_full_scalar/continuous_v1/bc_eft2_sequential_v1`.
The script refuses to overwrite any previous matching output. If rerunning,
choose another `--output-id`.

An algebraic test pass in the delivery environment is **not** an end-to-end
result: the original Windows-side saved EFT1 RGBeta and Matchete source files
must be available for the two-model run. The runner fails closed on missing
provenance, changed source hashes, scalar closure, or broken Weinberg projection.

## Physics follow-up to achieve genuine completion

The one-loop scalar matching coefficients must be calculated and certified at
**each** mass eigenstate threshold against a renormalised amplitude in the
correct EFT basis. Once supplied, these enter additively at the Y and X
boundaries, respectively, before continuing RGE evolution. The present output
cannot be relabelled physically certified simply by rerunning at higher
numerical precision.
