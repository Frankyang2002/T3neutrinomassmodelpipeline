Source baseline: GitHub `a02e04c6def5cf8522b2f612ccd6bff7d9963b91` (`main` as checked 2026-10-28). This batch reads **existing** experimental quadratic-EFT1 outputs and does not change production matching, RGEs, scalar potentials or thresholds.

## Physics and perturbative order

The 16-model manifest contains eight **model-specific** additional complex scalar bilinears:

- `A_+0`, `D_+0`, `E_+0`: holomorphic `(S1dag)^2 + h.c.`;
- `A_-2`, `D_-2`, `E_-2`: holomorphic `(S2dag)^2 + h.c.`;
- `B_-1`, `C_-1`: `eps(S1dag,S2dag) + h.c.`.

The other eight models have no such operator under the assumed gauge and Z2 symmetries. These are extra parameter *slots across models*, not eight independent couplings in each one.

For the declared candidate quadratic potential convention,

\[
V_2 = m_1^2 S_1^\dagger S_1 + m_2^2 S_2^\dagger S_2
    +\left[\mu_2\,\mathcal I_2(S_1,S_2) + \mathrm{h.c.}\right],
\]

there is **no hidden factor of 1/2** multiplying the holomorphic term.

For an allowed self-bilinear, the relevant complex scalar components split into real eigenmass branches

\[
m_{\mathrm{self},\pm}^2=m_{\mathrm{self}}^2\pm2|\mu_2|.
\]

For B/C opposite-hypercharge doublets, after rewriting `S2` as the conjugate isospin doublet, the quadratic matrix is

\[
M_\Phi^2=\begin{pmatrix}m_1^2&\mu_2\\ \mu_2^*&m_2^2\end{pmatrix},
\]

and its eigenvalues and mixing amplitude are

\[
m_\pm^2=\frac{m_1^2+m_2^2}{2}\pm
  \sqrt{\left(\frac{m_1^2-m_2^2}{2}\right)^2+|\mu_2|^2},
\quad
|\sin 2\theta|=\frac{2|\mu_2|}{\sqrt{(m_1^2-m_2^2)^2+4|\mu_2|^2}}.
\]

A nonzero quadratic insertion in the internal scalar propagator does **not** introduce a new loop factor. Therefore its effect can be present in the leading **one-loop** neutrino-mass coefficient. A small mass-eigenvalue difference is *not* a bound on the C5 difference: for nondegenerate masses, eigenvalue changes scale as `|mu2|^2 / |m1^2-m2^2|`, but the rotation of Yukawa and quartic tensors begins at order `|mu2| / |m1^2-m2^2|`. In general, the C5 response can be linear in a nonzero bilinear.

Accordingly, **no allowed nonzero quadratic term may be dismissed on the grounds that it is a higher-loop effect**. It may be set to zero as an explicit benchmark boundary condition, followed by an RG-source check. If it is generated radiatively, its insertion into a leading one-loop mass amplitude is formally at a higher fixed order relative to that boundary choice, subject to logarithmic enhancement.

## What this batch does

The new `scripts/AuditT3QuadraticImpact.py`:

1. Requires Batch 2's saved 16-model/50-quartic/8-bilinear inventory.
2. Requires the existing `output/general_t3_quadratic_eft1/all_models_quadratic_eft1_summary.json` and every per-model `*_eft1_quadratic_running.json` (already generated by the experimental RGBeta runner).
3. Validates each model's allowed additional quadratic structure against the source manifest and each report's **uncertified candidate** status/physics flags.
4. Independently reconstructs the analytic unbroken-gauge scalar eigenmass spectrum for the saved complex bilinear at both EFT1 endpoints and compares it to both spectra saved in the original run.
5. Recomputes the spectrum **setting only the bilinear to zero, at the same reported diagonal squared-masses**. This is *not* a new zero-bilinear RGE integration and does not reproduce its shifted ordinary couplings.
6. Saves a 16-model JSON audit, CSV diagnostic table and readable Markdown summary under `output/scalar_relevance/`.

The existing EFT1 candidate reports use a UV-to-EFT1 input scenario with `|mu2| = mu2_fraction * min(mS1Sq,mS2Sq)` at 100 TeV for eligible models. In the supplied saved `main` outputs the global fraction is 0.01; the eight ineligible models have zero, regardless of this global scenario value.

## Verification and remaining work

The 14 offline fixture tests verify mass spectra, 16-model coverage, the 1% scenario, the eight/no-bilinear model distinction, and fail-closed handling of missing or inconsistent evidence. These tests do not verify native Matchete/RGBeta.

The existing scalar quadratic spectrum library is explicitly a **candidate spherical SU(2) basis**; its physical Matchete/RGBeta component normalization is not certified. The spectra are gauge-unbroken quadratic spectra, not vacuum stability proofs or electroweak broken-phase masses.

**Next: targeted RGE source test at `mu2=0`** for all eight allowed bilinears, followed by a **nonzero-mixing direct C5 sensitivity check** wherever matching can be performed consistently. This is necessary before we can make a quantitative claim that setting these terms to zero changes neutrino masses by less than a chosen tolerance.
