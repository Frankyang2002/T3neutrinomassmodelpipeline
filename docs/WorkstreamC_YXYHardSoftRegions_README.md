## New calculation: method of regions for the scalar integral

Use Euclidean conventions and `d=4-2 epsilon`. The common `1/(16 pi^2)` factor is removed from the following formulas. Let `M=MY`, `m=MX`, `r=m^2/M^2`, with `0 < r < 1`:

\[
I(M,m)=\mu^{2\epsilon}\int\frac{d^dk}{(2\pi)^d}
  \frac{1}{(k^2+M^2)(k^2+m^2)}.
\]

After `MSbar` subtraction, the **full, unexpanded zero-momentum 1PI bubble** has

\[
16\pi^2 I_{\rm fin}(\mu)
=1+\ln\frac{\mu^2}{M^2}+\frac{r\ln r}{1-r}.
\]

This formula is exact for the scalar integral, **not** the EFT matching coefficient.
At `mu=M`, the strict leading hard region is `1`, and the finite-mass correction is

\[
\Delta_{XY}(r)=\sum_{n=1}^\infty r^n\ln r
=\frac{r\ln r}{1-r}.
\]

The first UV/IR-identified region coefficients are:

\[
\begin{array}{lll}
  \text{hard }n=0:& \epsilon_{\rm UV}^{-1}+1+\ln(\mu^2/M^2),
     &\text{UV pole;}\\
  \text{hard }n\ge 1:&
     r^n[\epsilon_{\rm IR}^{-1}+1+\ln(\mu^2/M^2)],
     &\text{IR pole;}\\
  \text{soft }n\ge 1:&
    -r^n[\epsilon_{\rm UV}^{-1}+1+\ln(\mu^2/m^2)],
     &\text{UV pole.}
\end{array}
\]

Thus the `n>=1` hard-IR and soft-UV poles cancel in the *combined* region expansion, and each finite sum is `r^n ln r`. Separating these pole labels is vital; treating scaleless soft terms as an independent zero would conceal a UV/IR cancellation.

**Power counting:** there is no order-`r^0` soft contribution to the mixed XY bubble at zero external momentum. The first nonzero soft region is order `r`, reproduced in an EFT2 calculation by a **dimension-seven** `LLHHXX/MY^2` operator generated by tree Y exchange, closed by a light-X tadpole. This is a *schematic* operator statement, not an explicit gauge-invariant Matchete matching or counterterm for this dim-7 basis. Higher powers `r^n` require corresponding higher derivative/mass insertions. Because `r~0.76`, their sum is not numerically negligible.

The script verifies region-pole residues, finite sums, exact geometric tail, v4 source-pole/finite equality, v6 XX subtraction and user-saved B/C masses. It does **not** manufacture the dim-7 operator, do EFT2 dim-7 renormalization, or convert `GammaCC` to physical `C5`. It does not multiply the physically matched coefficient by the full massive bubble factor.
