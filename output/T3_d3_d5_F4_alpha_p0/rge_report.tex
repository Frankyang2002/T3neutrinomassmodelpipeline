\begin{align*}
t&=\ln\mu,\\
V(H)&=\frac{\lambda_H}{2}(H^\dagger H)^2.
\end{align*}
The flavor construction assumes three lepton generations, a diagonal heavy-fermion mass basis, and common scalar masses.

\section{One-generation SMEFT check}
The tensor calculation is required to reproduce the compact one-generation benchmark
\begin{equation}
16\pi^2\beta_{C_5}=C_5\left[
-3g_2^2+2\lambda_H+6|y_u|^2+6|y_d|^2-|y_e|^2
\right].
\end{equation}
The RGE stage stops with an error if the calculated expression does not reduce to this benchmark.
\section{Three-generation flavor result}
The matched one-generation result is factorized as
\begin{equation*}
C_5^{(1)}=F_{\rm loop}\,\bar y_1\bar y_2,
\end{equation*}
and lifted to the symmetric flavor matrix
\begin{equation}
(C_5)_{pq}=\frac12\sum_r F_r\left[
y_{1,pr}^*y_{2,qr}^*+y_{2,pr}^*y_{1,qr}^*
\right].
\end{equation}
Writing this matrix as $K\equiv C_5$, the implemented RGE is
\begin{align}
16\pi^2\frac{dK}{d\ln\mu}
&=(2\lambda_H-3g_2^2+2T)K
-\frac32\left[Y_eY_e^\dagger K+K(Y_eY_e^\dagger)^T\right],\\
T&=\operatorname{Tr}\!\left(
Y_eY_e^\dagger+3Y_uY_u^\dagger+3Y_dY_d^\dagger
\right).
\end{align}
The fully expanded symbolic matrix is retained as a data file rather than printed here, because it is much less readable than the matrix equation above.
