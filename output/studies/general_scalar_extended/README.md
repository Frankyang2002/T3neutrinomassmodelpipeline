# Reserved — general scalar extension studies

Future T3 studies *including symmetry-allowed additional scalar operators* must
write separate, versioned results here. The historical restricted benchmarks
remain unmodified. **No general-potential numerical calculation has been run
by adding this README.**

Use study namespaces:

- `small_uv_running_5e-9/<run_id>/`
- `small_uv_frozen_5e-9/<run_id>/`
- `large_uv_frozen_0p5/<run_id>/`

Do not overwrite existing `<run_id>` folders. Include a per-run source-hash
manifest, supported interaction inventory, RG/matching scope, reference to
historical baseline results, and whether the physical Matchete/RGBeta
coupling map is certified. Until certified, label results **candidate**.

See `docs/T3_GENERAL_SCALAR_STUDY_SEPARATION.md`.
