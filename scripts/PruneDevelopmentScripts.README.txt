The -Apply command refuses to act if the exact 151-candidate inventory from
inspection differs, or if any candidate marked for deletion has local git changes.
It copies every removed file to a timestamped directory alongside the repository,
verifies SHA-256 for each copy, saves removal/protection manifests, and deletes
only after backups are complete.
